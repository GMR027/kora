# Kora 0.1.7

- Asistente local en Android: modelo Qwen2.5 0.5B que se descarga una sola vez
  (~475 MB) y funciona sin internet ni servidores externos.
- Activación con un botón desde Ajustes → IA local. Sin configurar URLs,
  proveedores ni modelos.
- Modo avanzado oculto tras un código para conectar Ollama o llama.cpp si se
  desea.
- Estudio de Voz: solo se muestran voces en español e inglés.
- Organización automática simplificada; usa el asistente local cuando está
  activo y pide confirmación antes de aplicar categorías.
- APK Android de 64 bits (`arm64` y `x86_64`) con `versionCode` 8.
